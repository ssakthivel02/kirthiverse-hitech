# KirthiVerse Pilot Metrics Protocol — Draft

> **STATUS: DRAFT — REQUIRES REVIEW/APPROVAL BEFORE REAL PILOT USE**
>
> This protocol defines descriptive evidence boundaries. It is not a research study protocol, statistical analysis plan, or proof of educational efficacy.

## 1. Pilot evidence purpose

Use P3–P8 to document bounded local controlled-pilot operation and activity without manufacturing historical evidence or upgrading activity counts into outcome claims.

## 2. Primary descriptive measures

The current controlled-pilot build can report, subject to P6 validation:

- observation days;
- whether a complete seven-day observation window exists;
- measured active-learning seconds/minutes on the bounded learning routes covered by P3;
- active days containing measured active-learning time;
- lesson starts and unique lessons started;
- lesson completions and unique lessons completed;
- Quick Skills sessions;
- diagnostic completions;
- answer checks;
- bounded mastery snapshots/movement when available.

The final protocol should name only measures actually needed for the approved pilot.

## 3. Measurement boundary

P3 begins from its own activation/baseline. Existing source evidence is baselined and is not backfilled as new pilot activity.

Active-learning time is intentionally conservative. The current P3 design measures time only on specified learner routes while the page is visible and recent interaction exists. It is not total device time, total educational time or attention measurement.

## 4. Seven-day wording

A P6-validated complete seven-day observation window may support wording that the run contains a **completed seven-day observation window**.

It does **not**, by itself, support:

- seven-day retention;
- a retention rate;
- continued engagement beyond the observed local activity;
- educational effectiveness.

If retention is a future outcome, define a separate participant-level return criterion, denominator, observation schedule and analysis method before collecting evidence for that claim.

## 5. Learning-improvement boundary

Do not infer learning improvement from activity counts, lesson completions or time spent alone.

A future learning-improvement claim requires a separately approved outcome design, for example an appropriate pre/post measurement and analysis plan with clear scoring, timing, inclusion/exclusion and interpretation rules. P3–P8 do not create that design automatically.

## 6. Multi-run aggregation

P7 may sum descriptive measures across independently P6-validated runs.

Allowed interpretation:

- number of validated local runs;
- number of runs with completed seven-day observation windows;
- sum of active minutes across runs;
- sum of active days across runs;
- sum of unique lesson completions across runs.

Important limitations:

- summed active days are not unique calendar days;
- summed lesson completions are not an efficacy measure;
- a group of runs is not automatically a research cohort;
- P7 does not compute cohort outcome/effect size/retention rate.

## 7. Evidence source hierarchy

Use the following chain for any external number:

1. original P5 frozen export;
2. P6 validation result and source SHA-256;
3. P7 pack for multi-run descriptive totals;
4. P8 claim-safe brief for bounded wording;
5. human review of the actual external document.

Do not type a number into a funding/partner document from memory when the validated source can be cited/rechecked.

## 8. Evidence exclusions

The metrics protocol must not treat the following as established by P3–P8:

- verified parent/guardian identity;
- legal consent;
- safeguarding approval/certification;
- school approval;
- research ethics approval;
- legal compliance certification;
- production readiness;
- tamper-evident/audited analytics;
- learning efficacy;
- retention;
- comparative effectiveness.

## 9. Protocol deviations

The final approved process should record material deviations, such as:

- assistance enabled contrary to plan;
- material downtime/defect;
- P4 HOLD during active run;
- participant/session schedule materially different from plan;
- deleted/lost evidence;
- manual browser-storage manipulation;
- evidence export after an unapproved process change.

Do not silently exclude a problematic run merely to improve external totals. Apply the approved inclusion/exclusion rule consistently and preserve the reason externally.

## 10. Analysis/wording approval

Before external publication/use, the responsible reviewer should confirm:

- the P6/P7/P8 status is valid for the intended statement;
- warnings/limitations are represented where material;
- no activity measure is presented as an outcome it does not establish;
- any separate outcome study is clearly distinguished from P3–P8 operational evidence.
