# KirthiVerse Global EdTech Benchmark & Award Roadmap — 2026

Status: approved post-production product strategy. This is feature-pattern research only: do not copy third-party branding, artwork, wording, code, proprietary game mechanics or content.

## Goal
Build KirthiVerse into a child-safe, bilingual-first learning ecosystem for ages 3–16, with Tamil and English as first-class experiences and a path to other Indian/world languages. Combine rigorous pedagogy, adaptive practice, family/school usefulness, accessibility, privacy, offline resilience and joyful original interaction design.

## Benchmark patterns

### Times Tables Rock Stars
References: https://ttrockstars.com/ · https://ttrockstars.com/schools/ · https://ttrockstars.com/parents/

Patterns worth learning from: short repeatable practice loops; adaptive question sequencing; anonymous learner aliases/avatars; optional competitions; actionable teacher statistics; homework; printable resources; certificates/celebration; accessibility controls such as declutter and timer hiding; curfews and break prompts; no child chat, ads or in-game purchases.

KirthiVerse response: no rock-star imitation. Build original KirthiVerse Worlds, Kiki missions, mastery constellations, local/private progress paths and culturally inclusive celebrations.

### IXL
References: https://uk.ixl.com/diagnostic · https://uk.ixl.com/help-centre/article/2956951/what-are-ixl-recommendations

Patterns: continuously updated diagnostic portrait; personalised next-step recommendations; prerequisite/building-block recommendations; challenge recommendations; class/admin analytics.

KirthiVerse response: transparent mastery map with “why this next?” explanations, age-appropriate prerequisite fallback and bilingual misconception support.

### Khan Academy
References: https://support.khanacademy.org/hc/en-us/articles/360039664491-What-can-I-do-from-the-Khan-Academy-Parent-Dashboard · https://support.khanacademy.org/hc/en-us/articles/360031129891-What-reporting-options-are-available-on-Khan-Academy-for-teachers-to-track-student-performance

Patterns: parent-child linking, parent assignments/progress, teacher dashboards, mastery goals, individual-student reports, assignment completion/responses and differentiated assignment.

KirthiVerse response: explicit guardian consent and role-scoped data; family/teacher views should emphasise actionable support rather than surveillance.

### Prodigy
References: https://www.prodigygame.com/main-en/teachers/reports · https://www.prodigygame.com/main-en/parents

Patterns: adaptive placement; curriculum-aligned assignments; assessment/progress/comprehension/usage reports; playful world progression; parent goals/reports; co-teacher/class management.

KirthiVerse response: quests remain learning-led; rewards never distort assessment or pressure children to purchase.

### CENTURY
References: https://support.century.tech/support/solutions/articles/44001847401/ · https://support.century.tech/support/solutions/articles/44002628201-smart-assignments-on-century

Patterns: bite-sized learning units; diagnostics feeding recommendations; AI-supported individualised assignments with teacher control; class/course/markbook/intervention views; guardian insight summaries.

KirthiVerse response: recommendations are explainable, bounded by verified curriculum metadata, and overridable by authorised adults/teachers.

## Role architecture

### Learner
- pseudonymous learner ID by default
- nickname/avatar with no public real-name exposure
- age/level path, language, interests, preferred worlds
- accessibility: reduced motion, reading support, contrast/font, Calm Mode, timer visibility
- local mastery, confidence, misconceptions, completed lessons, goals and streaks
- export/backup local progress

### Parent / guardian
- adult-owned identity only after cloud identity is approved
- link learner using time-limited QR/code plus explicit consent
- mastery/strength/gap/recommendation view
- assignments and healthy session goals/curfews
- control what may be shared to school/tutor
- bilingual weekly summary
- revoke links and export/delete data

### Teacher
- verified/authorised identity
- class code/roster only after governance approval
- class/group/individual assignments
- mastery heatmap and misconception clusters
- intervention/challenge groups
- curriculum/standards mapping
- print/offline packs
- parent-ready progress summaries
- no unrestricted private child messaging by default

### School administrator
- roster and teacher-role governance
- curriculum configuration
- aggregate mastery/usage views
- retention/export/delete controls
- access/role audit trail
- SSO/integrations only after privacy/security review

### Tutor / mentor
- guardian-approved learner-specific, time-bounded access
- assignments/progress support only within granted scope

## Original roadmap

### Phase 1 — Kiki Practice Arena
Local-only, uses canonical assessments.
- optional 3/5/10-minute missions
- adaptive queue from mistakes/confidence/mastery
- Calm Mode with no timer pressure
- timer hidden by default for younger learners
- Kiki hints/retry coaching
- personal-best against self, not compulsory public ranking
- private streak + healthy break prompts
- bilingual feedback
- no ads, purchases or public chat

### Phase 2 — Mastery Constellation
- subject/world mastery graph
- prerequisites/missing foundations
- explainable next-step recommendations
- lightweight diagnostic refresh
- concept-level evidence, not points only

### Phase 3 — Family Bridge prototype
Synthetic/local-only first; do not activate child cloud identity.
- guardian dashboard prototype
- weekly learning summary
- home assignments/goals
- accessibility/wellbeing controls
- explicit share/revoke model

### Phase 4 — Classroom Studio prototype
Synthetic class data first.
- class creation/codes
- assignments
- mastery heatmap
- misconception/intervention groups
- print/offline packs
- teacher time-saving recommendations
- parent-ready progress reports

### Phase 5 — Authorised cloud identity
Only after privacy, consent, security, retention and tenant-isolation gates.
- guardian-owned child linkage
- teacher/school RBAC
- consent ledger
- secure roster model
- encryption
- deletion/export/retention workflows
- audit logging

### Phase 6 — Safe community challenges
- anonymous aliases
- opt-in class/school challenges
- daily participation caps
- no public real names
- no open chat
- Hide Me option
- anti-cheating/fairness rules
- personal-growth/team formats, not speed only

## KirthiVerse differentiators
- Tamil + English first-class pedagogy, not translation as an afterthought
- broad learning worlds ages 3–16
- Kiki bilingual guide
- cross-subject quests/projects
- misconception-aware adaptive remediation
- local-first child privacy
- low-bandwidth/offline PWA
- calm/accessibility modes on every practice surface
- helpful rather than surveillance-oriented adult dashboards
- verified educational provenance
- Tamil/Indian cultural relevance plus global inclusion
- transparent recommendations

## Child-safety non-negotiables
- no behavioural advertising
- no child-targeted purchases
- no public real-name leaderboard
- no open child chat
- no manipulative infinite-play loop
- visible break/wellbeing controls
- guardian/teacher access explicit and revocable
- minimum necessary child data
- local-first default until approved cloud gates pass

## Evidence and award readiness
Award readiness requires evidence, not just visual polish: accessibility test results, privacy/security controls, learning-outcome studies, teacher/parent case studies, bilingual quality review, performance/offline evidence, inclusive-design evidence, privacy-respecting product measurement, and documented curriculum provenance. Submit claims to awards only when they can be evidenced.
